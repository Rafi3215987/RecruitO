# Fictional Hiring Policy: Job Description Structure

Every job description must include:
- Job title and seniority level
- A short role summary
- Key responsibilities
- Required qualifications
- Preferred qualifications, when applicable
- Work location or work mode

List essential qualifications under “Required” and optional ones under “Preferred.” Describe role-related skills and experience. Do not include requirements unrelated to doing the job.

Include an equal-opportunity statement in every public job description. Include a salary range only when one has been approved for publication.
