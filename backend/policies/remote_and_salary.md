# Fictional Hiring Policy: Work Mode and Compensation

State the work mode accurately: remote, hybrid, or on-site. If a role has location, time-zone, or in-office requirements, include them only when they are approved and relevant to the work.

Do not describe a role as fully remote if regular on-site attendance is required. Do not promise that applicants can work from every country or region unless that has been confirmed.

Include a salary range only when it has been approved for publication. State the currency and pay period clearly. Do not invent compensation figures or request an applicant’s salary history.
